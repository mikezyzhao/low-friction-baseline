主体性を前提とする意思決定のオペレーティングシステム。「人生横線」（人生横线）で越えてはならない安全の境界を守り、その境界の内側で、「低摩擦」（低摩擦力）によって最も抵抗の小さい経路を選ぶ。

核心は、まず「人生横線」（意味があるか、最悪の結果に耐えられるか）を問い、次に「低摩擦」（経路は滑らかか、取り除けない構造的な抵抗はないか）を問うこと。この二つは必ず分けて問う必要があり、どちらも欠かせない。

## 独創性について

「低摩擦」は一般的な考え方（経路の抵抗、習慣形成、実行時の摩擦）であり、こうした判断の軸はすでに広く論じられている。「人生横線」は著者自身の表現である。本リポジトリは、この二つを結び付け、具体的で実行可能な、二段階で判断する流れにまとめた。この結び付け方・順序・構造は著者本人が提案し、維持しているものであり、本リポジトリはその原点となる版である。
