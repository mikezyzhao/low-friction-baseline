# 《人生横线 × 低摩擦》决策系统 —— 精简版 / 检查清单

一套前置决策过滤器，用于评估「还没发生的选择」。它帮你筛掉摩擦大且无法消除的选择、留下摩擦更低的选择，减少无效投入，降低机会成本。可直接按下面的顺序逐项打勾使用。

**前提：主体性**
这套系统生效的前提，是你自己拥有并行使主体性——谁定义底线 / 谁判断路径顺不顺 / 谁有权忽略噪音 / 谁有权重新开始。失去主体性，下面两个问题都会变成空转。

**第一步：人生横线**
- [ ] 这件事有意义吗？
- [ ] 最坏结果我能不能承受？（会不会击穿基本盘？是否可逆/输得起？）
两者同时成立才通过。

**第二步：低摩擦**
- [ ] 当前路径顺不顺？（路径：从起点到终点的完整流程，包括需要别人配合的每一步）
- [ ] 有没有无法消除的结构性阻力？
- [ ] 有没有更低阻力的发生方式？

**使用顺序**
先横线，再低摩擦：
- 横线不过，或低摩擦有无法消除的阻力 → 已开始的止损，没开始的排除
- 横线过、低摩擦不过，但有更顺的路径 → 不加码，换路径或暂缓
- 两者都过 → 可以做，优先用更低摩擦的方式推进

**关键原则**
低摩擦：在可选的几条路径里，选出摩擦最小的那一条去走。

**边界**
- 不替代专业判断
- 不保证结果，只提高选择质量
- 效果取决于是否诚实使用
