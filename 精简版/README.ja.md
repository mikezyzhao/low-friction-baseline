> 翻訳版。内容に差異がある場合は中国語の原文（[README.md](README.md)）を正とする。2026-11-18 時点の中国語版を翻訳したもの。

まだ起きていない選択を評価するための、事前の意思決定フィルター。抵抗が大きく取り除けない選択を除外し、より摩擦の小さい選択を残すことで、無駄な投入を減らし、機会費用を下げる。下記の順序で、項目を一つずつチェックして使える。

**前提：主体性**
このシステムが機能する前提は、あなた自身が主体性を持ち、それを行使していること。誰が底線（越えてはならない下限）を定めるのか／誰が経路が滑らかかを判断するのか／誰が雑音を無視する権利を持つのか／誰がやり直す権利を持つのか。主体性を失うと、以下の二つの問いは空回りになる。

**第一歩：人生横線**
- [ ] この件に意味はあるか？
- [ ] 最悪の結果に耐えられるか？（基本的な土台を突き崩さないか？ 元に戻せるか／失っても耐えられるか？）

二つが同時に成り立って初めて通過。

**第二歩：低摩擦**
- [ ] 現在の経路は滑らかか？（経路：始点から終点までの全体の流れ。他者の協力が必要なすべての段階を含む）
- [ ] 取り除けない構造的な抵抗はないか？
- [ ] より抵抗の小さい進め方はないか？

**使う順序**
まず横線、次に低摩擦：
- 横線を通過しない、または低摩擦に取り除けない抵抗がある → すでに始めたことは損切りし、まだ始めていないことは除外する
- 横線は通過したが低摩擦は通過せず、より滑らかな経路がある → さらに投入せず、経路を変えるか、いったん保留にする
- 両方通過 → 実行してよい。そして、より摩擦の小さい方法を優先して進める

**複数の事柄から一つを選ぶとき**
それぞれの事柄について上の流れを最後まで通し、結果を一つの表に並べて比較する：

**重要な原則**
低摩擦：選択可能ないくつかの経路のうち、摩擦が最も小さいものを選んで進む。

**境界**
- 専門的な判断の代わりにはならない
- 結果は保証しない。選択の質を高めるだけである
- 効果は誠実に使うかどうかにかかっている
