# 《人生横线 × 低摩擦》决策系统

一套决策操作系统：以主体性为前提，用「人生横线」守住不可突破的安全边界，用「低摩擦力」在边界内挑选最顺的路径。

核心是先问「人生横线」（有意义 + 最坏结果能不能承受），再问「低摩擦」（路径顺不顺、有无无法消除的结构性阻力）——两者必须分开问，缺一不可。

- [`精简版/`](精简版) —— 一页纸版本
