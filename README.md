# 《人生横线 × 低摩擦》决策系统

一套决策操作系统：以主体性为前提，用「人生横线」守住不可突破的安全边界，用「低摩擦力」在边界内挑选最顺的路径。

两个版本：

- [`完整版/`](完整版) —— 含原则定义、二者关系、主体性前提，以及安全垫/阻尼/路径嵌入等配套工具概念
- [`精简版/`](精简版) —— 一页纸版本，只含两条原则本身和它们的关系
