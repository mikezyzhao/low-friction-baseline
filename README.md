# 《人生横线 × 低摩擦》决策系统

> 重要的不是你接触了多少信息、是否看过这套系统的核心，而是你把什么放在了最重要的位置。

一套决策操作系统：以主体性为前提，用「人生横线」守住不可突破的安全边界，用「低摩擦力」在边界内挑选阻力最小的路径。

核心是先问「人生横线」（有意义 + 最坏结果能不能承受），再问「低摩擦」（路径顺不顺、有无无法消除的结构性阻力）——两者必须分开问，缺一不可。

## 关于原创性

「低摩擦」作为一般性思路（路径阻力、习惯养成、执行摩擦）不是本仓库作者发明的，这类判断维度此前已被广泛讨论。「人生横线」是作者本人独有的表达。本仓库是作者把「人生横线」与「低摩擦」耦合成一套具体、可执行、分两步判断的流程——这套具体的耦合方式、排序和结构，是作者原创并作为源头持续维护的。
